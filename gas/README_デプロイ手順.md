# 受け口を作る手順

ページがシートを読むための受け口を、スプレッドシート側に作ります。1回だけの作業です。

## 1. Apps Scriptを開く

スプレッドシート「セッション報」を開いて、上のメニューから **拡張機能 → Apps Script** を押します。

## 2. コードを貼る

エディタに出ている中身を全部消して、このフォルダの `コード.gs` をそのまま貼ります。

## 3. 合言葉を決める

貼ったコードの上のほうに、この2行があります。

```js
var 合言葉 = 'ここに合言葉';
var シート名 = '';
```

`ここに合言葉` を、人に伝えたい言葉に書き換えます。半角の英数字がおすすめです。`シート名` は空のままなら1枚目のシートを読みます。

保存します(フロッピーのマーク、またはCtrl+S)。

## 4. デプロイする

1. 右上の **デプロイ → 新しいデプロイ**
2. 左の歯車を押して **ウェブアプリ** を選ぶ
3. **次のユーザーとして実行**: 自分
4. **アクセスできるユーザー**: 全員
5. **デプロイ** を押す
6. 初回は承認を求められます。自分のアカウントを選び、「詳細」→「安全ではないページに移動」→「許可」

「アクセスできるユーザー」に **全員** が出てこないときは、Google Workspaceの管理設定で外部公開が止められています。その場合は組織の中だけで見られる形になります。

## 5. URLを控える

デプロイが終わると、`https://script.google.com/macros/s/……/exec` というURLが出ます。これをコピーします。

このURLを `config.js` に書くと、ページがつながります。

## 直したいとき

コードを直したら、**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン: 新バージョン → デプロイ** の順で入れ替えます。URLは変わりません。

「新しいデプロイ」で作り直すとURLが変わるので、そのときは `config.js` も書き換えます。

## この受け口がやっていること

合言葉が合ったときだけ、シートの中身をそのまま返します。合わなければ何も返しません。シート自体はウェブに公開しません。
