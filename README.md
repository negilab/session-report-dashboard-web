# セッション報ダッシュボード(公開版)

スプレッドシート「セッション報」を、合言葉を知っている人だけが見られる1枚もののWebページです。ページを開くたびにシートを読み直すので、シートを直せばそのまま反映されます。

**このリポジトリに数字は入っていません。**数字はシートにあり、合言葉が合ったときだけ届きます。

## 見られる断面

上のタブで切り替えます。

1. **全体** — セッションを並べて比べる。記帳順の流れも
2. **セッションの中身** — セッションを1つ選び、その中の大項目を比べる
3. **日ごと** — 日ごとの合計。積み上げの色がその日に動いたセッション
4. **週ごと** — 月曜はじまりの週で同じもの

どのタブでも「見る数字」のプルダウンで、入力・キャッシュ作成・キャッシュ読み・出力・考えた分・作業時間の6つを切り替えられます。選んだものが、KPI・見出し・図・表・密度のすべてに効きます。

**作業時間を選んだときだけ、密度を出しません。**分を分で割ると必ず1になって意味が消えるためです。そのときは密度のカードと明細の密度列が消えます。

棒に触れると中身が出ます。携帯ではタップです。

## 大項目と中項目

大項目は中項目の束ねです。同じ大項目に中項目が2件入っていれば「×2」と出ます。集計は大項目の単位で足しています。

## 動かすのに要るもの

ページと、Apps Scriptの受け口の2つです。受け口の作り方は [gas/README_デプロイ手順.md](gas/README_デプロイ手順.md) にあります。

受け口ができたら、その `/exec` で終わるURLを `config.js` に書きます。

```js
window.CONFIG = { endpoint: "https://script.google.com/macros/s/xxxx/exec" };
```

## 合言葉

`gas/コード.gs` の先頭にあります。ここを書き換えてデプロイし直すと、合言葉が変わります。ページ側には合言葉を持たせていません。

一度入れた合言葉はブラウザに残ります。消すときは右上の「閉じる」を押します。

## 作り

素のHTML/CSS/JavaScriptだけです。ライブラリもCDNも使っていません。図はSVGではなくHTMLで組み立てています(SVGの文字は細く出て、背景に沈むため)。

セッションの色は7本を順ぐりに配ります。並びは起ち上がった時刻の順で、8本目は1本目に戻ります。ライトとダークの両方の値を持っています。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `app.js` | 集計と描画。`startDashboard(明細)` を呼ぶと立ち上がる |
| `gate.js` | 合言葉・シートの取得・1分ごとの取り直し |
| `config.js` | つなぎ先のURL |
| `style.css` | 見た目 |
| `gas/コード.gs` | Apps Scriptに貼る受け口 |

## 数字の扱い

- 合計行は読まず、明細から足し直しています
- トークンは中項目1行ずつまで手元ログの実測です。**サブエージェントを使った分も入っています**
- 備考に「※実測0」とある行は、書いてある開始時刻と実際に動いていた時刻がずれていて、その分が隣の行に寄っています
- 日ごと・週ごとは、開始時刻ではなくセッション名の日付でまとめています。日をまたいだ作業を、1つのセッションのまま数えるためです
